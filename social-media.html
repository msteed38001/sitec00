Social Media: The Local Publishing Pipeline

The Social Media app isn't just a database - it's a local asset generation pipeline.

Built on the exact same Micro-Kernel interface as Cardex and TUIDex, this app takes structured data (quotes, stats, war stories) and renders them into pixel-perfect PNGs and PDFs using Pillow. It formats content specifically for LinkedIn and Instagram, entirely on your local machine.

No Canva subscriptions. No cloud API limits. Just pure Python generating high-resolution graphics.

Batch Processing

Instead of creating graphics one by one, you define a "batch." The engine reads the entries in your sort order, applies the layout template, and exports the entire series as PNGs and PDFs in seconds.

Template-Driven Layouts

The visual style is controlled by a templates.toml file. You can define fonts, color palettes, canvas sizes, margins, and text-wrapping rules. Change the TOML, and the entire output style changes instantly.

Why Local Generation?

Tools like Canva are great, but they require a browser, a subscription, and a stable internet connection. If you are pushing out content regularly, you need a system that is repeatable and fast.

By keeping this in the terminal, you can write a quote, assign it a template, and export a batch of 20 high-res PNGs in seconds. The output is deterministic. The layout engine doesn't break. And because it's part of the Micro-Kernel, your source data is stored locally in SQLite.

How does the Pillow renderer work?

The render.py module is a custom plug-in for the Social Media app. It reads the [canvas] and [base] settings from the TOML file (width, height, background color, fonts, sizes). It takes the text from the database, calculates the text wrapping, applies the correct margins, and draws everything onto the image buffer before saving.

What formats does it support?

The app primarily outputs 1080x1350 images optimized for Instagram and LinkedIn, but the canvas size and PDF page size are controlled in the TOML. You can export directly to PDF if you want to create a multi-page carousel or a printed document.
