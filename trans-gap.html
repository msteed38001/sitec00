The PYTD vs. YTD Autopsy

Standard ERP reports show what sold. This tool shows what stopped selling.

Transaction Gaps is a pure Python CLI tool that compares Prior Year-To-Date (PYTD) to Current Year-To-Date (YTD) at the customer, vendor, and item level. It ignores the noise of standard dashboards and dives into the raw transaction stream to identify true lost sales, expose hidden product line swaps, and find the customer churn hiding behind flat revenue.

The "Vendor Swap" Trap

A sales rep can swap one product line for another just to hit an activity KPI. The overall revenue looks flat, but the customer is actually churning. Transaction Gaps catches this by comparing the exact vendor spend in the prior window against the current window.

Configurable Time Windows

You aren't locked into a trailing 12-month view. The script accepts command-line arguments to define the exact date ranges you want to compare. You can audit Q1 vs Q1, or compare 2024 to 2025, without editing a single line of code.

The Output

The script groups the output into three distinct buckets: LOST (bought in the old window, not the new), NEW (bought in the new window, not the old), and SAME (bought in both windows, but the quantity or vendor changed).

The Runtime Options

Because it's a CLI script, it's incredibly flexible. You can run a broad sweep across the whole database, or drill down into a single customer or vendor to trace the exact evidence. 

# Run the full PYTD vs YTD gap analysis
python src/inventory/trans_gap.py

# Drill down into a specific customer
python src/inventory/trans_gap.py --customer 64628

# Filter by a specific vendor
python src/inventory/trans_gap.py --vendor 98600

# Define custom prior and current date windows
python src/inventory/trans_gap.py --prior 2025-01-01:2025-12-31 --current 2026-01-01:2026-12-31

# Dump every row tagged prior/current/neither for debugging
python src/inventory/trans_gap.py --dump
Why build this as a CLI script?

ERPs are great at storing data, but their reporting engines often force you into rigid, pre-defined views. If you want to compare a custom date range across specific vendors, you usually have to export to Excel and build a pivot table.

This script gives you the raw analytical power of Python directly against the SQLite database. It runs in milliseconds, outputs clean CSV files for further analysis, and doesn't require a BI dashboard or a cloud connection.
