The Local-First Web

No WordPress. No AWS. Just a custom-built Python engine rendering static pages from an 8GB machine. Modern web delivery through veteran data engineering.

The site you are looking at right now was built with a 1,500-line Python script.

I didn't use WordPress. I didn't use Webflow. I didn't use a single line of React, Bootstrap, or Tailwind.

I built my own static site generator. It runs locally, compiles in milliseconds, and outputs pure HTML and CSS.

Why build my own?

Because modern web development is a mess. If you want a simple website, you have to install a CMS, manage plugins, fight with updates, and hope the server doesn't crash.

I wanted a tool that did exactly what I needed, and nothing more. So I built it.

Custom Markdown Parser

Standard Markdown is too flat for complex layouts. So I extended it. I can write :::columns or :::card or :::chart in a text file, and my engine parses it into responsive HTML components.

Math-Based Colors

I am color blind. I can't see a color wheel. So I built a theme generator. I give it a base hex code, and it mathematically generates a harmonious, WCAG-compliant color palette.

The "No Framework" Advantage

Look at the source code of this page. You won't find a single utility class. You won't find a massive CSS framework clogging up the network request.

I write pure CSS. I use native flexbox. I use standard media queries.

Because the engine is built on pure data and pure CSS, the site loads instantly. It works offline. It requires zero maintenance. There is no database to hack, no plugins to update, and no cloud server to pay for.

The Engine in Action

This isn't a drag-and-drop builder. It is a data pipeline. I don't pick colors; I generate them mathematically. Here are the actual commands that built the themes on this site:

# Generating a light theme from a medical blue
python src/manage.py generate --name "Hospital Light" --base "#0055A4" --mode "light"

# Generating a dark theme from a neon hacker green
python src/manage.py generate --name "Terminal Dark" --base "hacker_green" --mode "dark"

# Manually overriding the button text to black for readability
python src/manage.py tweak --id 7 --field btn_text --value "#000000"

# Compiling the static site
python src/build.py --site intranet
